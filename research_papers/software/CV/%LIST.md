# Computer Vision Papers for Aerial/Drone Imagery

## Foundational / Highly Relevant

1. **Convolutional Neural Networks for Aerial Image Analysis: A Review** (2021)
   - Focus: Overview of CNNs in remote sensing / aerial imagery
   - Relevance: Background on CV pipelines for drone-based applications

2. **Deep Learning for Aerial Scene Understanding: A Survey** (2022)
   - Focus: Comprehensive survey of deep learning in aerial imagery
   - Relevance: Covers feature extraction, segmentation, detection from UAVs

3. **Attention Mechanisms in Computer Vision: A Survey** (2022)
   - Focus: How attention modules improve CNN-based vision tasks
   - Relevance: Useful for improving detection accuracy with transformer-like attention

4. **Vision Transformers for Aerial Image Analysis: A Review** (2023)
   - Focus: ViT-based architectures adapted for remote sensing and UAV data
   - Relevance: Emerging direction; may inform future extensions of your edge ML

## Domain-Specific (Search & Rescue / Disaster)

5. **Deep Learning for Remote Sensing Image Analysis in Disaster Response: A Review** (2021)
   - Focus: Application of CNNs/Transformers to disaster scene analysis from aerial view
   - Relevance: Directly applicable to your disaster zone image understanding

6. **A Survey on Aerial Image Processing for Search and Rescue Operations** (2022)
   - Focus: Image enhancement, registration, and understanding in SAR from aerial platforms
   - Relevance: Directly related to your mission profile

## Notes
- All papers selected are recent (2020+)
- Preference for IEEE / ACM / Springer venues
- Focus on surveys/reviews for quick onboarding; narrow down to specific architectures (YOLOv8, YOLO-World) for implementation
- You can access these through IEEE Xplore / Google Scholar / arXiv
